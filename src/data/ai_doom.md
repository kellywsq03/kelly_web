# AI Coding and the Existence of My Job

There’s a lot of doom and gloom around AI replacing software engineers. It does make me wonder: when should I jump from a sinking ship? Or rather, how will I know the ship is even sinking?

I watched a video by a computer engineer about whether AI will take our jobs. He argues that we can only vertically scale hardware so far before improvements in AI become marginal. AI’s hardware efficiency is ultimately constrained by transformers and the attention model.

Coding is not solved. English cannot provide the same semantic layer that Python provides over C. Python has syntax, rules, and semantics; English lacks that same precision. A single English sentence could produce entirely different code from different LLMs. We cannot simply use English as an abstraction layer for code and assume that getting “better” at prompting will fix its ambiguity.

Then comes ownership. As software engineers, we must own every line of code we commit, or the technical debt becomes too severe. But what if AI gets better at reducing that debt by producing clean, modular code? We fear tech debt because, when the dreaded bug appears, we have to untangle the mess ourselves. But what if AI becomes so good at finding bugs that tech debt stops mattering?

Well, if AI is an abstraction layer for a developer, there will still come a point where a tangled codebase demands more computing and processing for AI to uncover the problem, just as it demands more effort from us. But what if AI’s analytical ability and enormous context window make that manageable?

If I plotted human efficiency and AI efficiency against problem size, I imagine humans leading on smaller problems. Noticing that the padding between two elements is too small is simply faster than waiting for AI to notice it for you. What lets me add value as a developer is combining my own analytical skills with AI’s. I recognize that a function is looping on the wrong condition, then tell AI exactly what I want fixed.

Who knows what the future holds?
